# shadcn MCP Reference

## shadcn Registry MCP

- Find components → `mcp__shadcn__list_items_in_registries`
- Component examples → `mcp__shadcn__get_item_examples_from_registries`
- Install commands → `mcp__shadcn__get_add_command_for_items`
- Search → `mcp__shadcn__search_items_in_registries`
- Audit usage → `mcp__shadcn__get_audit_checklist`

## shadcn/ui MCP

- Browse → `mcp__shadcn-ui__list_components`, `mcp__shadcn-ui__get_component`
- Demos → `mcp__shadcn-ui__get_component_demo`
- Themes → `mcp__shadcn-ui__get_theme`, `mcp__shadcn-ui__apply_theme`
- Blocks → `mcp__shadcn-ui__list_blocks`, `mcp__shadcn-ui__get_block`

## Install Pattern

```bash
npx shadcn@latest add <component-name>
```

Components → `src/components/ui/`. Style: base-nova, neutral base, CSS variables.
